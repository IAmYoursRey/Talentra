Use the TALENTRA.ID workspace system in this repository.

Start with **Phase 1 only** from `TALENTRA/PHASES.md`.

Requirements:
- Use `talentra-orchestrator` as coordinator.
- Delegate UI implementation to `talentra-ui`.
- Do not implement the real backend, database, JWT authentication, recommendation engine, or PDF/QR logic yet.
- Build stable typed adapters and mock data so later phases can replace mocks without redesigning the screens.
- Implement all Phase 1 routes and states for student, teacher, admin, and public verification.
- Make it mobile-first and PWA-oriented.
- Run the Phase 1 review and acceptance checks.
- Update `TALENTRA/state/phase-state.json` when finished.
- Stop after Phase 1 and report completed items, tests/checks, remaining issues, and the files changed.
